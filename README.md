# GitHub Final Project: Simple Interest Calculator

## Project Description

The Simple Interest Calculator calculates the simple interest on a principal amount based on the annual rate of interest and the time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Annual rate of interest
- Time period in years

## Output

The calculated simple interest.

## Technologies Used

- Bash scripting
- Linux command line

## How to Run

1. Open a terminal.
2. Navigate to the project directory.
3. Run the script using `bash simple-interest.sh`.
4. Enter the principal amount, rate of interest, and time period.
5. View the calculated simple interest.

## Project Objective

This project demonstrates basic Bash scripting, user input, arithmetic calculations, and command-line operations.
